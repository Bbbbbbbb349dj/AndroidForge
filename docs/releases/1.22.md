# Nuvio Enhanced 1.22 (220)

## CloudStream extension browser

Settings → Content & Discovery → CloudStream now opens a repository-first browser inspired by the supplied CloudStream screenshots:

- Repository icons, names, descriptions and actual installed/total counts; search, refresh, enable/disable and confirmed removal.
- Add repository floating action; direct manifest URLs and MegaRepo discovery. Discovered repositories remain opt-in through Advanced management.
- Open a repository to browse its extensions with icon, language, version, package size, description and download/update/installed actions.
- Movie, Series, Anime, Cartoon and Asian Drama chips, language selection, extension search and status filters.
- Live Downloaded / Disabled / Not downloaded totals and a proportional status bar. These are disjoint buckets; installed providers in a disabled repository count as disabled.
- Virtualized extension/repository lists. No screenshots' example repositories or counts are fabricated or silently installed.
- Extension detail sheets retain enable/disable, pinning, configuration, update/reinstall, removal and compatibility information. Existing bulk tools and UI-mode preferences remain under Advanced management & settings.
- Third-party code consent and platform compatibility checks remain enforced. Repository removal asks for confirmation because it also removes that repository's installed extensions.

## Tap source → first-frame playback

- Default ExoPlayer startup-buffer hold is now **0 ms**: start when the extractor/decoder has enough media for playback, without first accumulating an additional one-second buffer.
- MPV disables initial cache-fill pausing (`cache-pause-initial=no`), retaining normal read-ahead/cache and rebuffer protection.
- HLS quality inspection waits until playback is running so its duplicate master request does not compete with first-frame loading. It remains bounded/cancellable and never restarts the adaptive master automatically.
- Subtitle catalog updates no longer recreate ExoPlayer's media item or trigger another prepare cycle. Subtitle selections continue through the existing subtitle controller.
- Explicit custom buffer settings remain authoritative. Network rebuffer protection remains 2.5 seconds by default; local playback keeps a separate 250 ms recovery threshold. Background downloading/read-ahead is not disabled to make a startup claim.

**Limits:** this removes application-added waits; it cannot eliminate DNS/TLS, provider response time, HLS segment availability, file container/index reads, codec initialization, debrid/torrent resolution, or insufficient network throughput. It cannot guarantee literal instantaneous playback or zero stalls for arbitrary internet sources. No speculative background downloads of every source are started.

## Verification and upgrade identity

- Version 1.22 / code 220; original package ID `com.nuvio.enhanced`. The abandoned separate-package experiment is not included.
- Upgrade signing must match the actually delivered v1.21 fresh-install APK, not the older v1.20 certificate. No private signing material is downloaded or committed.
- APK publication additionally requires zip alignment checks and installation of the exact signed ARM64 APK on an Android 16 (API 36) Google APIs emulator. This is not a physical Moto G85 test.
- Focused Kotlin suite includes existing v1.21 / v1.19 regressions plus v1.22 browser/count/filter/startup-policy tests. Run `./gradlew -Pnuvio.android.distribution=full -Pnuvio.testSuite=v122 :composeApp:testAndroidHostTest`.
- Six Python verifier/installer-gate tests cover certificate matching and publication blocking on Android installation/wrong-version failures. Existing unrelated legacy test compilation limitations remain documented in 1.21.md.

Device confirmation is still required for visual fidelity, actual tap-to-first-frame times, provider playback and sustained buffering behavior. The earlier reported invalid-package incident was resolved by the user identifying that a different app had been downloaded; it is not evidence of a defect in this app's installer.
