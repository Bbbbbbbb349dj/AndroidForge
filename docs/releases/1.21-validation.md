## Publication blocked — do not work around this by uninstalling

The final public-certificate comparison with the released v1.20 APK failed: the candidate uses a different signing certificate. The workflow deliberately stopped before uploading/publishing the APK. This is not a source compilation failure.

The original keystore cache exists on `arena/17a4641a-androidforge`; Actions caches are scoped by branch. An original release key made available through the repository's secure `NUVIO_RELEASE_KEYSTORE_BASE64`, `NUVIO_RELEASE_STORE_PASSWORD`, `NUVIO_RELEASE_KEY_ALIAS` and, if necessary, `NUVIO_RELEASE_KEY_PASSWORD` Actions secrets permits the same branch's workflow to sign a compatible update. Never put private keys/passwords in chat or commit them. No private signing material was retrieved to this workspace.

Source publication does not depend on private signing material. The separate source-only export contains the tested v1.21 app changes.

## Scope of automated tests

The `-Pnuvio.testSuite=v121` release gate compiles/runs the v1.21 regression tests plus the existing v1.19 verification class. Without that property the full inherited suite remains present; unrelated legacy server tests in the pinned archive currently reference removed APIs and fail compilation. Those tests were not silently deleted or represented as passing.
