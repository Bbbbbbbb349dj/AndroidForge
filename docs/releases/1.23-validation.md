# 1.23 validation status

Status: implementation under validation; no v1.23 APK has been verified or published yet.

The preceding v1.22 build/install gates passed, but the user reported severe runtime lag. A successful installation is not playback acceptance.

1.23 introduces a bounded default startup buffer, eliminates player live-frame capture, redesigns bottom controls/recommendations, and embeds LibVLC. The pipeline requires source reconstruction, focused unit tests, release compilation, APK/native alignment, v1.21 signer continuity, exact signed APK installation on API 36 and a separate debug native VLC smoke test before publication.

No physical Moto G85 performance measurements are available. Update this document with actual CI results rather than inferring them from source inspection.
