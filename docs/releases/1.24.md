# Nuvio Enhanced 1.24 (240)

## Player
- Remove the full-width boxed bottom slab in both legacy and modern layouts.
- Use a single horizontally scrollable action row, with Night and Discover integrated into it. No secondary feature-button row or capsule around a capsule.
- Keep individual theme-colored control backings and border separation when glass is disabled. No video-frame readback is reintroduced.
- Thin legacy seekbar, slimmer thumb and subtle chapter ticks; retain seeking, chapter jumps, speed, tracks, sources, quality, PiP and existing preferences.

## Profile
- Compact avatar/name header with edit and profile switching actions.
- Paired viewing-time and seven-day activity summary instead of huge stacked cards.
- Collection navigation as a grouped list with counts, icons and working collection sheets; includes Continue, Library, Completed, Upcoming, Watched and Ongoing, plus episode count.
- Readable genre bars and movie/series balance, retaining real data, loading/partial-data disclosures, refresh and taste tags.

## Delivery scope
One build-only run authorized by the user. Tests, debug APK and emulator checks omitted. Full signed ARM64 release with code/resource shrinking disabled, so the APK is larger. Package/version/signing continuity and native alignment checks remain. No claim of physical-device UI or performance acceptance.

Built-in VLC, rich recommendation sheet, Downloads/unlimited downloads, Library categories, all-catalog search, subtitle caching, rating positioning and the CloudStream repository browser remain.
