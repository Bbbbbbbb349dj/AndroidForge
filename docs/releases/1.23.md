# Nuvio Enhanced 1.23 (230)

## Player stability rework
- Remove decoded-video PixelCopy capture from the player composition and live refraction/blur on control surfaces. No per-frame bitmap copies for player glass; use inexpensive tinted surfaces instead.
- Restore a 1.5-second default startup buffer and MPV initial cache pausing. Explicit custom buffers remain supported. This prioritizes a viable decoding queue over zero-wait startup; network/provider problems can still stall playback.
- Move modern-layout title/metadata into a separate top header, freeing the bottom deck for seeking and actions. Keep center transport at a stable position rather than moving it with measured title/control heights.

## Bottom controls and recommendations
- Night Mode and Recommendations are in the measured bottom controls in both modern and legacy layouts, not a side rail. Night Mode is disabled with an explanation on engines/configurations that cannot apply the effect.
- Manual recommendations open a bottom sheet on phones and landscape layouts, with poster art, year, rating, runtime, genres, provider synopsis and a details action. Missing provider metadata is disclosed, not fabricated.
- End-of-movie discovery uses a compact bottom-centered prompt; the full list opens only when requested.
- Glass Backgrounds on Controls OFF means opaque theme-colored surfaces, outline separation and matching text/icon colors. ON uses static tinted translucency without decoded-frame readback.

## Embedded VLC
- Include VideoLAN `org.videolan.android:libvlc-all:3.7.8` as a native in-app engine. Select **Playback → Playback Engine → VLC (built-in)**; no external VLC installation is required. The player engine button cycles ExoPlayer → MPV → VLC → ExoPlayer.
- Support native video rendering, play/pause, seek/resume, speed, volume, embedded/external subtitle selection, audio selection/delay, subtitle delay, resize and lifecycle cleanup. Native stop/release is dispatched off the UI thread.
- LibVLC 3.x does not provide ExoPlayer's arbitrary HTTP request/response overrides. Protected-header, separate-audio and chunked YouTube sources fall back to ExoPlayer with an explanatory message, rather than dropping authentication.
- VLC does **not** implement this app's Night Mode DynamicsProcessing effect, styled Compose subtitle renderer, disc-title UI or seek-preview extraction. Existing ExoPlayer/MPV choices remain available. VLC uses its own native subtitle appearance.
- VideoLAN attribution is included in Settings → Licenses; this GPL v3 app includes GPL/LGPL components under their respective licenses. LibVLC JNI source: https://code.videolan.org/videolan/libvlcjni ; VLC source: https://code.videolan.org/videolan/vlc

## Preserved
Downloads navigation, unlimited downloads, rating position, Library categories, all-catalog search, removed type chip/spacing, download subtitle caching, profile insights, StreamPlay/CineStream and repository-first CloudStream browser remain intact.

## Validation requirements
The workflow blocks publication until focused v1.19/v1.21/v1.22/v1.23 tests, full Android release compilation, APK/native alignment, signing continuity, exact signed APK Android 16 installation and a **separate debug-build native VLC playback/lifecycle smoke test** pass. The native test exercises local decode, advancing position, seek/speed, pause, lifecycle return and surface recreation.

These checks are not physical Moto G85 performance validation, network-stream acceptance, or a claim that all lag is fixed. Runtime testing on the user's device is still required. Keep the installed app/data; the release must retain the delivered v1.21/v1.22 signer and package ID.
